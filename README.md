# NiZ Web

NiZ mini84 的浏览器配置工具，使用原厂协议和 WebHID。界面依据 Wootility v5.4.2 的实际演示页面重做：深色双栏导航、顶部配置与保存栏、键盘旁的层选择、下方的按键编辑和功能库。

适配型号：mini84EC(S) V2.3.3，USB 0483:5235，84 键 × 9 层。无需安装桌面驱动，保留原厂固件；不是 QMK 固件或 VIA 协议的移植。

## 使用

使用桌面 Chrome 或 Edge 打开已部署的 HTTPS 页面，点击「连接键盘」，在浏览器授权框选择 mini84。连接后读取全部配置并自动保存本地备份。

- 点击键帽、选择功能，再点「应用此键」。也可以把功能拖到键帽上。
- 右键点击键帽可撤销该键的修改。
- 组合模式可加入 Command / Win、Option / Alt、Shift 等功能；也可通过「录入快捷键」捕获当前页内的快捷键。系统保留的组合请手动选择。
- 宏和连发使用 NiZ 原厂报告。固定间隔、循环次数可编辑；重新编辑已有复杂宏会转为固定间隔模式，其他宏保持原始报告。
- 最后点击右上角「保存到键盘」，检查变更，确认后自动备份、完整写入 756 条定义并读回核对。
- 「备份与恢复」支持导入 / 导出 JSON，兼容本项目原生 Mac 应用生成的完整 JSON。连接设备时导入仅更换按键映射；离线导入保留整份备份数据。

离线演示不能向硬件写入。未保存的编辑保存在当前页面，关闭前请导出。本地备份使用 IndexedDB，清除站点数据、更换浏览器或隐私模式可能使其不可见；重要配置请下载留存。

## 实机验证

已通过网页 WebHID 直接访问真实 mini84，完成读取与一次当前配置原样回写。写入前本地备份保存成功；写后 756 条定义、252 字节触发参数和 252 字节灯光数据全部一致。按键定义 SHA-256 与原生版本验收结果一致：

`cc5b51846866aae44493e558ef4e89a820e3490391df35f9c23321b34563f4ce`

10 项协议 / 传输检查与 10 项浏览器交互检查通过，见 `VALIDATION.json`。协议检查包括不完整配置、重复记录、宏分包、备份失败时禁止开始写入、外部配置变更拒绝及完整写入 / 读回模拟。浏览器检查包括拖放改键、右键撤销、快捷键、宏、层切换和 390px 布局。

本次实机写入没有修改键位功能。改动后的实际按键行为、宏播放、拔线断电后的持久化仍待进一步验收。

## 当前边界

- 仅支持该 mini84 固件家族的 USB 连接；其他 NiZ 型号、蓝牙和 2.4G 尚未适配。
- 触发参数只读展示，不把未解析的字节解释为毫米或克数。
- 当前为非 RGB 设备；灯光区域随备份保留，不开放 RGB 控制。
- 校准与固件升级尚未移植。
- 9 层使用原始编号，未将尚未核对的配置组 / Fn 关系标为已确认。
- 写入中断可能留下部分变更。应用不自动宣称恢复成功；请重新读取，从写入前备份恢复到编辑器，再检查并写入。

## 数据与部署

无第三方运行依赖、统计脚本、外部字体或云端配置数据库。键位、宏、按键计数在浏览器和 USB 设备之间处理，不通过网站服务端传输。网站源代码不包含个人键盘配置、按键计数或原生备份文件。

使用 Sites 发布为当前账号私有站点。站点登录仅用于访问网页，不参与键盘数据处理。HTTPS 站点和 localhost 都可用 WebHID；file:// 不作为验证入口。

## 本地开发

```sh
node --test tests/*.test.mjs
python3 -m http.server 4179 --bind 127.0.0.1 --directory dist
```

在 `http://127.0.0.1:4179/` 打开。可通过环境变量 `NIZ_NATIVE_FIXTURE=/absolute/path/backup.json` 让协议检查额外读取一份本机原生备份，该文件不会加入项目。

主要文件：`dist/protocol.js` 是 NiZ 报告编解码；`dist/hid.js` 是 WebHID 通信；`dist/storage.js` 处理浏览器备份；`dist/app.js` 负责交互。部署清单见 `.openai/hosting.json`。
